# Connect the Superhive repository for updates

Pink Fix has no built-in updater. Updates come through Superhive's remote extension
repository, which Blender 4.2 and later can check for you.

## Connect it

1. Buy Pink Fix on Superhive and open the **receipt page**. It has the install
   instructions and a drag-and-drop link.
2. Drag the extension from the receipt page into Blender.
3. When Blender asks whether to add **Superhive** as a remote repository, accept.

Your past and future Superhive extensions then appear in Blender with one-click install,
and updates can be installed from inside Blender.

## Install an update

Open **Edit > Preferences > Get Extensions**. Use the menu at the top right of that tab to
check for updates and install them; an available update also shows next to Pink Fix in
the list.
