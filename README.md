# Pink Fix documentation

User documentation for **Pink Fix**, a Blender extension that finds, relinks and packs
missing textures and files. Pink Fix itself is sold on Superhive; this repository holds
only the documentation (no source code).

Published at https://itsnickp.github.io/pinkfix-docs/

Build locally: `pip install mkdocs-material` then `mkdocs serve` (or `mkdocs build --strict`).
